# SemSearch — логотип

Знак «Точка» (B·1): лупа, у которой вместо ручки — найденная точка. Кольцо и точка на одной оси под 45°.
Надпись SemSearch нарисована из тех же окружностей, шрифт не используется — лицензия не нужна.
Полное руководство с примерами — на холсте «SemSearch — логотип», ряд «Комплект».

## Файлы

| Папка | Что внутри |
|---|---|
| `logo/svg/` | Мастер-файлы. `symbol*` — знак, `horizontal*` — основная компоновка, `stacked*` — вертикальная, `wordmark*` — только надпись. Без суффикса — графит, `-blue` — фирменный синий, `-white` — для тёмного фона (чуть тоньше), `-black` — чистый чёрный для печати. `symbol-small*` — версия для 16 px. |
| `logo/png/` | Готовые PNG с прозрачным фоном для документов и соцсетей. |
| `icons/app/` | Значок приложения: `icon.ico` (16–256; в 16 и 20 px — знак без плитки), PNG для Tauri. |
| `icons/tray/` | Значки трея 16/20/24/32 px, синий трея — виден на тёмной и светлой панели. |
| `icons/web/` | favicon и набор веб-иконок, если понадобится сайт. |
| `_backup-old-icons/` | Прежние иконки и файлы с лупой — на случай отката. |

## Цвета

| Цвет | HEX | RGB | CMYK | Где |
|---|---|---|---|---|
| Синий SemSearch | `#005FB8` | 0 95 184 | 100 48 0 28 · Pantone ≈ 2935 C | Знак, плитка, акцент интерфейса |
| Графит | `#1A1A1A` | 26 26 26 | 0 0 0 90 | Текст, одноцветный знак |
| Синий трея | `#2B88D8` | 43 136 216 | 80 37 0 15 | Только трей и значки до 20 px |
| Белый / фон | `#FFFFFF` / `#F3F3F3` | — | — | Фоны; белый знак на синем и графите |

Pantone и CMYK — ближайшие значения, перед печатью сверьте по веернику.

## Правила

- Охранное поле — диаметр точки со всех сторон.
- Минимум: знак 16 px (5 мм), горизонтальная 96 px (25 мм), вертикальная 64 px (18 мм).
- До 20 px — `symbol-small`, крупнее — основной знак.
- Знак всегда одного цвета; точку отдельно не перекрашивать, не поворачивать, не растягивать, без теней.
- Синий знак на графите не ставить (контраст 2,8 : 1) — на тёмном только белый.

## Что уже заменено в приложении

- `shell/icons/` — значок приложения и трея (`icon.ico`, PNG, `tray-16…32.png`).
- `ui/icon.svg` — значок окон.
- `ui/tray.html`, `shell/dist/tray.html` — знак в шапке меню трея.
- `shell/dist/index.html` — знак на экране загрузки.

Иконки трея и приложения вшиваются в `SemSearch.exe` при сборке, поэтому их видно только после пересборки:
`cd shell && cargo build --release`.

Проверку на уникальность как товарного знака не проводили — перед регистрацией стоит заказать её у специалиста.
