## Возможности

- **По смыслу, а не по словам** — «договор про крышу» найдёт «Договор подряда №14 — кровля.pdf» и покажет нужную страницу.
- **Фото и видео** — по описанию или по картинке, в видео — с точностью до секунды.
- **Код** — найдёт нужную функцию; чужие библиотеки и сборки выдачу не засоряют.
- **Имена** — все файлы на всех дисках за миллисекунды, как в Everything.
- **Не мешает играм** — уступает видеокарту, а в полноэкранной игре встаёт на паузу.
- **Без интернета** — файлы и запросы не покидают компьютер.

<details>
<summary><b>Как мерили</b></summary>
<br>

Скрипт [`tools/bench_search.py`](tools/bench_search.py): 5 запросов по части имени и 5 фраз, каждый 10 раз после прогрева,
в таблице — медиана. Время — от отправки запроса до получения всех результатов. Поиск Windows спрашивался через тот же
индекс, что у Проводника. Шкала на графике логарифмическая.

| | SemSearch | Поиск Windows |
|---|---|---|
| По имени по всему диску C:, первые 200 файлов | 13 мс — свой индекс имён всего диска (3,5 млн файлов). Вместе с поиском по смыслу, который окно запускает на каждый запрос, — 148 мс | 3 мин 50 с — перебор диска (`dir /s`), как у Проводника вне индекса. Свой индекс у Windows по умолчанию только для `C:\Users` и меню «Пуск»: там ответ за 14 мс |
| По смыслу, фраза | 102 мс; нашлось 21–54 файла на фразу | Не умеет. Поиск по словам (FREETEXT) отвечает за 4,8 мс, но по 2 фразам из 5 не нашёл ни одного файла |

Компьютер: Intel Core i5-13600KF, NVIDIA GeForce RTX 4070 SUPER, SSD; 16 октября 2026. Повторить у себя (SemSearch должен
быть запущен и не индексировать): `.venv\Scripts\python.exe tools\bench_search.py --walk`, затем
`.venv\Scripts\python.exe tools\make_readme_images.py speed` перерисует график.

</details>

## Установка

1. Скачайте `SemSearch-Setup-<версия>.exe` со страницы [Releases](../../releases) и запустите. Программа ставится для
   текущего пользователя (по умолчанию в `%LOCALAPPDATA%\Programs\SemSearch`), права администратора не нужны.
2. Windows спросит разрешение только на Visual C++ (если его нет) и на быстрый поиск по имени — задачу Планировщика,
   которая читает MFT. От неё можно отказаться: тогда имена ищутся обычным обходом, медленнее.
3. Во время установки скачиваются модель (~1,5 ГБ) и PyTorch — с CUDA, если есть видеокарта NVIDIA, иначе для
   процессора. Нужен интернет; оборвалась сеть — «Повторить».

Установщик пока не подписан, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».
Новая версия ставится тем же установщиком поверх старой — настройки, индекс и модель сохраняются. Удаляется SemSearch
через «Приложения» или «Установка и удаление программ»; при удалении можно стереть и настройки, индекс и модель.

| Что нужно | |
|---|---|
| Система | Windows 11 или Windows 10 (версия 1709 и новее), 64-бит. macOS и Linux не поддерживаются |
| Видеокарта | NVIDIA RTX 20xx или новее — по желанию. Без неё (или со старой картой) модель считает на процессоре, медленнее |
| WebView2 Runtime | В Windows 11 уже есть, в Windows 10 обычно ставится вместе с Edge; если нет — установщик предложит его поставить |
| Место на диске | ~7 ГБ с видеокартой NVIDIA, ~3,5 ГБ без неё: окружение Python, модель ~1,5 ГБ и индекс |

<details>
<summary><b>Сборка из исходников</b></summary>
<br>

Нужны Python 3.11 или новее, [Rust](https://rustup.rs) и Visual Studio Build Tools с компонентом «Разработка
классических приложений на C++».

1. Окружение Python — PyTorch с CUDA, если есть драйвер NVIDIA, иначе сборка для процессора:
   ```bat
   setup.bat
   ```
2. `SemSearch.exe` и движок имён `bin\semsearch-engine.exe`:
   ```bat
   build.cmd
   ```
3. Запустите `SemSearch.exe`. При первом запуске скачивается модель (~1,5 ГБ) — экран запуска показывает, сколько
   осталось. Искать по имени можно сразу.

Без `build.cmd` после `setup.bat` можно запустить `start.bat`: поиск откроется в браузере, горячая клавиша будет
открывать его там же, значка в трее нет, а имена будут искаться встроенным обходом — медленнее. Свой установщик
собирает `build-installer.cmd` (см. «Разработка»).

</details>

<details>
<summary><b>Быстрый поиск по имени через MFT (права администратора)</b></summary>
<br>

Чтобы читать MFT и журнал USN, движку нужны права администратора. Для этого есть задача Планировщика
«SemSearch Engine»: она стартует при входе в Windows без запроса UAC. Установщик ставит её сам, если вы согласились;
при сборке из исходников — так:

```bat
engine\install-task.cmd
```

Скрипт спросит UAC (нужна учётная запись администратора) и скопирует движок в `%ProgramFiles%\SemSearch\` — туда без
прав администратора не записать, так что подменить его нельзя. Журнал движка — `%ProgramFiles%\SemSearch\logs\engine.log`,
из папки данных он читает только список дисков (`config.json`). После пересборки запустите скрипт ещё раз, чтобы обновить копию.
Удалить задачу и копию: `engine\uninstall-task.cmd`.

Без задачи backend запускает `bin\semsearch-engine.exe` сам, без прав: обход диска + `ReadDirectoryChangesW`.
Индекс имён строится дольше, всё остальное так же. Так же, обходом, индексируются диски не NTFS (exFAT, FAT32, ReFS).

</details>

## Как пользоваться

Нажмите <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> и опишите, что ищете. Например:

- «договор про крышу», «смета на кухню» — документы;
- «кот на балконе», «скриншот с ошибкой CUDA» — фото, кадры из видео;
- «где парсил JSON с ретраями» — код.

| Клавиши | Что делают |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> | Показать или спрятать окно из любой программы. Если в ваших раскладках AltGr+S набирает букву (польская, чешская, венгерская…), при первом запуске выбирается <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Пробел</kbd>. Меняется в «Настройках» |
| <kbd>Esc</kbd> | Спрятать окно |
| <kbd>↑</kbd> <kbd>↓</kbd> | Выбрать результат |
| <kbd>Enter</kbd> | Открыть файл |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Показать в папке |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>7</kbd> | Вкладки: всё, документы, код, фото, видео, аудио, по имени |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Найти похожие фото и кадры |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Копировать путь |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Искать по картинке из буфера обмена (или перетащите её в окно) |

Язык (русский, английский или как в Windows), тема, автозапуск, папки, диски, исключения и паузы — в «Настройках»:
кнопка внизу окна или меню в трее.

## Как устроено

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/images/architecture-ru-dark.png">
  <img src="docs/images/architecture-ru-light.png" alt="Схема: SemSearch.exe, backend на Python и движок имён на Rust работают на вашем компьютере; из интернета только один раз скачивается модель">
</picture>

| Часть | Что делает |
|---|---|
| `SemSearch.exe` (Rust, Tauri 2; исходники `shell/`) | Окна без рамки, трей, горячая клавиша, автозапуск. Запускает backend и перезапускает его при сбое |
| `server.py` → `app.py` (Python) | Модель EmbeddingGemma 2 (на видеокарте, если она подходит), индекс содержимого, API для интерфейса |
| `ui/` | Интерфейс 1:1 по макету «SemSearch Desktop» (исходники макета — `design/`). Значки типов файлов — `ui/filetypes/` |
| Движок имён (Rust; исходники `engine/`) | Имена всех файлов на дисках: MFT + журнал USN или обход папок. Поиск по имени за миллисекунды и поток изменений файлов |
| Установщик (Rust, Tauri 2; исходники `installer/`) | Ставит Python, PyTorch, модель, задачу движка и ярлыки для текущего пользователя, обновляет и удаляет программу. Подробно — [`docs/INSTALLER.md`](docs/INSTALLER.md) |

Контракты между частями — [`docs/API.md`](docs/API.md).

<details>
<summary><b>Что и в каком порядке индексируется</b></summary>
<br>

- **По смыслу** — папка пользователя и известные папки вне неё (например, «Документы», перенесённые на другой диск),
  кроме AppData, папок с точкой и `node_modules`. Файлы OneDrive, которые есть на диске, индексируются, а файлы «только
  в облаке» не скачиваются — по имени они находятся. Порядок: документы → код → фото → аудио → видео.
- **По имени** — все несъёмные диски; список меняется в «Настройках».
- **Сборки и зависимости** узнаются по файлам проекта рядом, а не по имени папки: `bin`/`obj` рядом с `.csproj`, `Library`
  в проекте Unity, `Saved`/`Intermediate` рядом с `.uproject`, папка с `pyvenv.cfg` и т. п. Обычная папка «Library» с книгами в поиск попадает.
- **Чужой код** (настройка «Чужой код и библиотеки»): git-подмодули, скачанные архивы исходников (`*-main`, `*-master`, `*-1.2.3`),
  то, что `.gitignore` проекта считает не исходниками, и сгенерированные файлы по умолчанию не индексируются. Клоны чужих
  репозиториев без ваших коммитов и файлы с шапкой библиотеки — в последнюю очередь. Касается только кода и `.md`/`.rst`.
- **Сканы PDF**: страница почти без текста идёт в модель картинкой, поэтому отсканированный договор тоже находится.
- **Изменения** подхватываются через журнал изменений за секунды: файл берётся в работу, когда в него 3 секунды ничего
  не пишут. Раз в 6 часов — страховочный полный обход.
- **Внешние и медленные диски**: HDD, флешки и сетевые диски читаются в меньшее число потоков. Внешний диск можно
  «Безопасно извлечь» — SemSearch отпускает его сам и снова подхватывает после подключения; индекс его содержимого
  при этом не стирается.

| Тип | Расширения |
|---|---|
| Документы | PDF, DOCX, TXT, MD, RST, ORG, TEX |
| Код | 45 расширений: Python, JS/TS, C#, C/C++, Java, Kotlin, Go, Rust, PHP, Lua, SQL, шейдеры, YAML, TOML… |
| Фото | JPG, PNG, WEBP, BMP, GIF, TIFF |
| Аудио | MP3, WAV, FLAC, OGG, M4A, OPUS, AAC, WMA |
| Видео | MP4, MKV, AVI, MOV, WEBM, WMV, M4V |

</details>

<details>
<summary><b>Как SemSearch уступает видеокарту</b></summary>
<br>

Нагрузка подстраивается сама (`throttle.py`): работа режется на кусочки по 1–5 мс, чтобы кадры игр и рабочего стола
проходили между ними. Пока вы за компьютером — мягкий режим, при тяжёлой игре в окне — сильное ограничение, когда вас
нет — полная скорость (но не на ноутбуке от батареи и не в режиме экономии заряда). Полноэкранные игры и фильмы, а также
процессы из списка в «Настройках» ставят индексацию на паузу.

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/images/settings-ru-dark.png">
  <img src="docs/images/settings-ru-light.png" alt="Настройки: пауза в полноэкранных приложениях и при запуске выбранных программ, отрезки видео и аудио, состояние индекса">
</picture>

Текстовая часть модели идёт CUDA-графами, по графу на слой (`cudagraphs.py`): кусочек подаётся видеокарте одним вызовом,
а не ~50 мелкими, и за то же время успевает сделать в 1,5–2,5 раза больше работы.

Порции подстраиваются под видеокарту: на медленной они меньше, на карте с 2–4 ГБ памяти — по свободной видеопамяти.
Если torch не умеет работать с вашей видеокартой (сборка с CUDA 12.8 поддерживает RTX 20xx и новее, а не GTX 10xx),
драйвер слишком старый или видеопамяти не хватает даже на модель, она считает на процессоре — причина записана
в `semsearch.log`.

</details>

### Где хранятся данные

`%LOCALAPPDATA%\SemSearch` — настройки (`config.json`), индексы, превью, журналы и модель (`models\`, ~1,5 ГБ). Папка
программы во время работы только читается, поэтому её можно положить куда угодно, в том числе в `Program Files`.

- Другая папка для данных — переменная окружения `SEMSEARCH_DATA_DIR` (абсолютный путь). Задайте её как постоянную
  переменную пользователя — тогда её увидит и движок, запущенный задачей Планировщика.
- Если рядом с программой остались `data\` и `config.json` от старой версии, при первом запуске они переносятся сюда.
- Модель, скачанная прежними версиями в общий кэш Hugging Face (`%USERPROFILE%\.cache\huggingface\hub`), при первом
  запуске тоже переносится сюда — заново её качать не придётся. Свой кэш (`HF_HUB_CACHE`) SemSearch не трогает.

## Если что-то не так

Журналы лежат в `%LOCALAPPDATA%\SemSearch`: `semsearch.log` (backend), `shell.log` (окно и трей), `engine.log`
(движок без задачи). Журнал движка из задачи — `%ProgramFiles%\SemSearch\logs\engine.log`.

<details>
<summary><b>Файл не находится</b></summary>
<br>

Проверьте, что его папка входит в «Поиск по смыслу» и не попала в исключения («Настройки» → «Где искать»). Там же, в разделе
«Индекс», — список файлов, которые не удалось прочитать, и кнопка «Собрать индекс заново».

</details>

<details>
<summary><b>Горячая клавиша набирает букву или не открывает окно</b></summary>
<br>

<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+буква — это <kbd>AltGr</kbd>+буква, которым в польской, чешской, венгерской и других
раскладках набирают буквы. SemSearch учитывает раскладки, установленные при первом запуске; если раскладку добавили
позже и клавиша мешает, смените её в «Настройках». Если сочетание занято другой программой, «Настройки» об этом скажут.

</details>

<details>
<summary><b>Программа не запускается</b></summary>
<br>

- Нет WebView2 Runtime — SemSearch скажет об этом при запуске и откроет страницу загрузки.
- Сервер поиска не запускается с кодом 0xC0000135 — не хватает Microsoft Visual C++ Redistributable (x64), он нужен
  PyTorch. Установщик ставит его сам.

</details>

<details>
<summary><b>Порт 8765 занят другой программой</b></summary>
<br>

Например, AnkiConnect. SemSearch сам займёт свободный порт рядом; свой порт можно задать в `config.json` (`"port"`).

</details>

<details>
<summary><b>Индексация идёт на процессоре, хотя видеокарта есть</b></summary>
<br>

Причина записана в `semsearch.log`. Обычно это видеокарта старше RTX 20xx (сборка torch с CUDA 12.8 их не поддерживает),
слишком старый драйвер NVIDIA — тогда в журнале написано, что его стоит обновить, — или нехватка видеопамяти.

</details>

## Разработка

- `setup.bat` — окружение Python; версии зафиксированы в `requirements-torch.txt` (torch, torchvision) и `requirements.txt`.
- `build.cmd` — release-сборка движка (`engine\`) и оболочки (`shell\`); кладёт `bin\semsearch-engine.exe` и `SemSearch.exe`
  в корень. Нужны Rust (минимальная версия — `rust-version` в `Cargo.toml`) и Visual Studio Build Tools (MSVC и Windows SDK).
  Движок и оболочка собираются со статическим CRT, поэтому ни `SemSearch.exe`, ни движку VC++ Redistributable не нужен.
- `installer\` и `build-installer.cmd` — установщик `dist\SemSearch-Setup-<версия>.exe`; что и как он делает, какие файлы
  кладёт (`installer\payload.txt`) — в [`docs/INSTALLER.md`](docs/INSTALLER.md). `tools\fetch_model.py` — шаг установщика,
  который скачивает модель; вручную: `.venv\Scripts\python.exe tools\fetch_model.py`.
- Подпись установщика, `SemSearch.exe` и движка необязательна: без неё сборка идёт без подписи. Сертификат выбирает
  переменная `SEMSEARCH_SIGN` с аргументами signtool — файл (`/f C:\keys\semsearch.pfx /p <пароль>`), хранилище Windows
  или токен (`/sha1 <отпечаток>`) либо Azure Trusted Signing (`/dlib <…\Azure.CodeSigning.Dlib.dll> /dmdf <…\metadata.json>`).
  Ещё: `SEMSEARCH_SIGNTOOL` (путь к signtool.exe, по умолчанию — из Windows Kits 10), `SEMSEARCH_SIGN_TS` (сервер меток
  времени, по умолчанию DigiCert), `SEMSEARCH_SIGN_TEST=1` (самоподписанный сертификат для проверки сборки).
- `mock_api.py` — сервер с данными из макета для вёрстки интерфейса (порт 8799). Экран запуска: `/dev/scenario/boot`,
  `firstrun`, `cpu`, `booterror`, `bootnet`, `hold-download`, `hold-model`; язык: `/dev/lang/<system|ru|en>` (по-английски и демо-файлы английские).
- `tools\make_readme_images.py` — картинки обоих README (`docs\images\`): скриншоты и ролик интерфейса на данных
  `mock_api.py` и схема устройства, по-русски и по-английски. Нужен Edge или Chrome; запускать, когда меняется интерфейс.
- `tools\bench_search.py` — замер скорости поиска против поиска Windows для графика в этом README.
- `tools\make_filetype_icons.py` — значки типов файлов (`ui\filetypes\`); запускать, только когда меняются сами значки
  или список расширений.
- `tools\frameprobe` (Rust) и `tools\gpu_bench.py` — замер плавности кадров под нагрузкой индексации.
- Переменные окружения (`SEMSEARCH_DATA_DIR`, `SEMSEARCH_PORT`, `SEMSEARCH_ROOT`, `SEMSEARCH_DEV_URL`,
  `SEMSEARCH_NO_BACKEND`) и контракты между частями — в [`docs/API.md`](docs/API.md).
- Логотип, иконки и цвета — в [`brand/`](brand/README.md).

в том числе в коммерческих продуктах, если приложить текст лицензии, сохранить указания авторства и отметить свои изменения.
Права на название и логотип SemSearch лицензия не даёт.

- Значки типов файлов в `ui/filetypes/` — на основе набора `@pierre/trees` (тоже Apache-2.0, подробности
  в [`ui/filetypes/LICENSE`](ui/filetypes/LICENSE)).
- Модель EmbeddingGemma 2 в репозиторий не входит: она скачивается с Hugging Face при установке (из исходников — при
