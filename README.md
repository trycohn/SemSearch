# SemSearch — поиск по компьютеру по смыслу и по имени

Локальный поиск на EmbeddingGemma 2: документы, код, фото, видео и аудио ищутся обычной фразой
(«договор про крышу», «кот на балконе», «где парсил JSON с ретраями»), а имена файлов — по всем
дискам мгновенно, как в Everything. Ничего не уходит в интернет.

## Требования

- Windows 10 версии 1709 или новее, 64-бит. Программа работает только в Windows.
- Python 3.11 или новее.
- Видеокарта NVIDIA RTX 20xx или новее — по желанию: без неё (или со старой картой) модель считает на процессоре, медленнее.
- WebView2 Runtime — в Windows 11 уже есть, в Windows 10 обычно ставится вместе с Edge.
- Около 7 ГБ на диске: окружение Python (~5 ГБ), модель (~1,5 ГБ, скачается при первом запуске) и индекс.
- Для сборки `SemSearch.exe` и движка имён — Rust и Visual Studio Build Tools (см. «Разработка»).

## Установка и запуск

1. `setup.bat` — окружение Python: PyTorch с CUDA, если есть драйвер NVIDIA, иначе сборка для процессора.
2. `build.cmd` — собирает `SemSearch.exe` и `bin\semsearch-engine.exe`.
3. `SemSearch.exe` — окно поиска; программа живёт в трее. Без сборки можно запустить `start.bat` —
   поиск откроется в браузере, а имена будут искаться встроенным обходом (медленнее).
4. По желанию — `engine\install-task.cmd`, чтобы имена индексировались через MFT (см. «Движок имён»).

## Управление

- **Ctrl+Alt+S** — показать/спрятать окно из любой программы, **Esc** — спрятать.
- Enter — открыть файл, Ctrl+Enter — показать в папке, ↑/↓ — выбор, Ctrl+1…7 — вкладки,
  Ctrl+F — найти похожие фото/кадры, Ctrl+Shift+C — копировать путь,
  картинку можно перетащить в окно или вставить через Ctrl+V.
- Автозапуск с Windows, тема, папки, диски, исключения, паузы — в «Настройках» (кнопка внизу окна или меню в трее).

## Из чего состоит

| Часть | Что делает |
|---|---|
| `SemSearch.exe` (Rust, Tauri; исходники `shell/`) | Окна без рамки, трей, горячая клавиша, автозапуск. Запускает и при сбое перезапускает backend. |
| `server.py` → `app.py` (Python) | Модель EmbeddingGemma 2 (на видеокарте, если она подходит), индекс содержимого, API для интерфейса. |
| `ui/` | Интерфейс 1:1 по макету «SemSearch Desktop» (исходники макета — `design/`). |
| Движок имён (Rust; исходники `engine/`) | Индекс имён всех файлов на дисках: MFT + журнал USN или обход папок. Отдаёт поиск по имени за миллисекунды и поток изменений файлов. |

Контракты между частями — `docs/API.md`.

## Где хранятся данные

`%LOCALAPPDATA%\SemSearch` — настройки (`config.json`), индексы, превью, журналы. Папка программы во время
работы только читается, поэтому её можно положить куда угодно, в том числе в `Program Files`.

- Другая папка для данных — переменная окружения `SEMSEARCH_DATA_DIR` (абсолютный путь). Задайте её как постоянную
  переменную пользователя — тогда её увидит и движок, запущенный задачей Планировщика.
- Если рядом с программой остались `data\` и `config.json` от старой версии, при первом запуске они переносятся сюда.

## Движок имён и права администратора

Чтобы читать MFT, движку нужны права администратора. Для этого есть задача Планировщика «SemSearch Engine»:
она стартует при входе в Windows без запроса UAC. Файл движка копируется в `%ProgramFiles%\SemSearch\`
(туда без прав администратора не записать — подменить его нельзя), журнал — `%ProgramFiles%\SemSearch\logs\engine.log`.
Из папки данных движок читает только список дисков (`config.json`).

- Установить или обновить после пересборки: `engine\install-task.cmd` (спросит UAC; нужна учётная запись администратора).
- Удалить задачу и копию в Program Files: `engine\uninstall-task.cmd`.
- Без задачи backend запускает `bin\semsearch-engine.exe` сам, без прав: обход диска + ReadDirectoryChangesW
  (индекс строится дольше, всё остальное так же). Так же, обходом, индексируются диски не NTFS (exFAT, FAT32, ReFS).

## Индексация и игры

- По смыслу индексируется папка пользователя и известные папки вне неё (например, «Документы», перенесённые
  на другой диск), кроме AppData, папок с точкой и node_modules; облачные файлы OneDrive не скачиваются.
  Сборки и зависимости узнаются по файлам проекта рядом, а не по одному имени папки: `bin`/`obj` рядом
  с `.csproj`, `Library` в проекте Unity, `Saved`/`Intermediate` рядом с `.uproject`, папка с `pyvenv.cfg`
  и т. п. — обычная папка «Library» с книгами в поиск попадает. Порядок: документы → код → фото → аудио → видео.
- По имени — все несъёмные диски; список меняется в «Настройках».
- Чужой код (настройка «Чужой код и библиотеки»): git-подмодули, скачанные архивы исходников (`*-main`,
  `*-master`, `*-1.2.3`), то, что `.gitignore` проекта считает не исходниками, и сгенерированные файлы
  по умолчанию не индексируются; клоны чужих репозиториев без ваших коммитов и файлы с шапкой библиотеки
  индексируются в последнюю очередь. Касается только кода и `.md`/`.rst`. Точные копии файлов считаются
  один раз — в выдаче «ещё N копий».
- Новые, изменённые, переименованные и удалённые файлы подхватываются через журнал изменений за секунды
  (файл берётся в работу, когда в него 3 секунды ничего не пишут). Раз в 6 часов — страховочный полный обход.
- Нагрузка на видеокарту подстраивается (`throttle.py`): работа режется на кусочки по 1–5 мс, чтобы кадры
  игр и рабочего стола проходили между ними. Пока вы за компьютером — мягкий режим, при тяжёлой игре в окне —
  сильное ограничение, когда вас нет — полная скорость. Полноэкранные игры и фильмы ставят индексацию на паузу.
- Если torch не умеет работать с вашей видеокартой (сборка с CUDA 12.8 поддерживает RTX 20xx и новее, а не GTX 10xx)
  или модели не хватает видеопамяти, она автоматически считает на процессоре — причина записана в `semsearch.log`.

## Если что-то не так

Журналы лежат в `%LOCALAPPDATA%\SemSearch`: `semsearch.log` (backend), `shell.log` (окно и трей), `engine.log`
(движок без задачи). Журнал движка из задачи — `%ProgramFiles%\SemSearch\logs\engine.log`. В «Настройках» есть
список файлов, которые не удалось прочитать, и кнопка «Собрать индекс заново».

- Порт 8765 занят другой программой (например, AnkiConnect) — SemSearch сам займёт свободный порт рядом.
  Свой порт можно задать в `config.json` (`"port"`).
- В польской, чешской, венгерской и некоторых других раскладках Ctrl+Alt+S — это AltGr+S, которым набирают буквы.
  Если клавиша мешает, смените её в «Настройках».

## Разработка

- `setup.bat` — окружение Python; версии зафиксированы в `setup.bat` (torch) и `requirements.txt`.
- `build.cmd` — release-сборка движка (`engine\`) и оболочки (`shell\`); кладёт `bin\semsearch-engine.exe` и
  `SemSearch.exe` в корень. Нужны Rust (rustup; минимальная версия — `rust-version` в `Cargo.toml`) и Visual Studio
  Build Tools с компонентом «Разработка классических приложений на C++» (MSVC и Windows SDK). Движок собирается
  со статическим CRT, поэтому VC++ Redistributable не нужен.
- `mock_api.py` — сервер с данными из макета для вёрстки интерфейса (порт 8799).
- `tools\frameprobe` (Rust) и `tools\gpu_bench.py` — замер плавности кадров под нагрузкой индексации.
- Переменные окружения (`SEMSEARCH_DATA_DIR`, `SEMSEARCH_PORT`, `SEMSEARCH_ROOT`, `SEMSEARCH_DEV_URL`,
  `SEMSEARCH_NO_BACKEND`) и контракты между частями — в `docs/API.md`.
